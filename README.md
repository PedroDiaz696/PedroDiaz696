## Proyectos destacados

### CrediYa — Sistema de cobros de cartera

Aplicación de consola en Java para gestionar la cartera de créditos de una empresa: empleados, clientes, préstamos, pagos y reportes, con persistencia en MySQL y respaldo en archivos de texto.

**Tecnologías:** Java 21 · Maven · MySQL 8 · JDBC · Stream API y Lambda

**Aporte:** Diseño e implementación completa: arquitectura por capas (model, service, DAO, validación, excepciones), POO con herencia y polimorfismo, transacciones con commit/rollback para los pagos, validaciones centralizadas, reportes con Stream API y diagrama de clases UML.

**Enlaces:** [Ver repositorio](https://github.com/PedroDiaz696/Proyecto_CrediYa_DiazPedro)

### Hotel El Rincón del Carmen

Sitio web para un hotel con landing page, consulta de disponibilidad y reservas, página de contacto, registro e inicio de sesión de usuarios y panel de administración. Diseño mobile first y responsive.

**Tecnologías:** HTML · CSS · JavaScript

**Aporte:** Desarrollo en equipo del sitio, organizado en módulos (páginas, estilos, scripts y componentes como el carrusel).

**Enlaces:** [Ver repositorio](https://github.com/PedroDiaz696/proyecto_HotelRincon_PedroDiazJulianAgudelo)

### Gestión académica de campus

Aplicación de consola en Python para administrar un campus de formación, con menús por rol (coordinador, trainer y camper), y operaciones para consultar, actualizar y eliminar registros, guardados en archivos JSON.

**Tecnologías:** Python · JSON

**Aporte:** Desarrollo en equipo de la lógica de los módulos y del manejo de datos persistentes.

**Enlaces:** [Ver repositorio](https://github.com/PedroDiaz696/Proyecto_Python_DiazPedroSepulvedaKeyner)
